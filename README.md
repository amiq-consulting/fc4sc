# FC4SC Repository Notice

This repository is archived and is no longer the primary development repository for FC4SC.

FC4SC was originally developed by **AMIQ Consulting** and was later contributed to the **Accellera SystemC Verification Working Group**. Accellera subsequently took over the ongoing development of FC4SC and now maintains the official reference implementation.

The original repository is kept here for historical reference. 

For **FC4SC** development, issues, and contributions, please follow the official Accellera repository: 
<https://github.com/accellera-official/fc4sc>
